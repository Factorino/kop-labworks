# kop-labworks — агрегатор личного блога

Веб-приложение для автора личного блога. Пост создаётся один раз и
публикуется из одного места во все подключённые каналы: веб-блог,
Telegram-канал и группу ВКонтакте. По каждому каналу видно, дошёл ли пост;
при сбое внешнего API публикация повторяется.

Учебный проект по дисциплине «Конструирование программного обеспечения» (УлГТУ).

## Ветки

| Ветка | Назначение |
| --- | --- |
| `master` | Выпущенные версии и общие для всех частей файлы репозитория |
| `backend` | Разработка серверной части (Python, FastAPI) |
| `frontend` | Разработка веб-интерфейса (React, TypeScript) |
| `feat/*`, `fix/*`, `test/*`, `ci/*`, `build/*`, `docs/*` | Одна задача; сливаются в `backend` или `frontend` |

Серверная часть и интерфейс разрабатываются в отдельных ветках и попадают в
`master` при выпуске версии. Правила ветвления, слияния и выпуска версий — в
[CONTRIBUTING.md](CONTRIBUTING.md).

## Структура репозитория

| Путь | Содержимое | Ветка |
| --- | --- | --- |
| `.github/` | Шаблоны pull request и issue, CI/CD, Dependabot | `master` |
| `.pre-commit-config.yaml`, `.cz.toml` | Git-хуки, формат коммитов и версий | `master` |
| `CHANGELOG.md` | Изменения по версиям, формируется из истории коммитов | `master` |
| `src/kop/` | Серверная часть: домен, сценарии, инфраструктура, API | `backend` |
| `tests/` | Модульные, интеграционные и сквозные тесты | `backend` |
| `scripts/` | Служебные скрипты: срез метрик версии | `backend` |
| `docs/metrics/` | Метрики проекта по версиям | `backend` |
| `docker/` | Образ приложения и конфигурации Docker Compose | `backend` |
| `frontend/` | Веб-интерфейс | `frontend` |

## Задачи

Задачи ведутся в YouTrack, проект `KOP`. Pull request ссылается на задачу
строкой `Refs: KOP-NN` в описании.
